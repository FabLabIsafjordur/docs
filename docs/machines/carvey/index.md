# Carvey

## Overview

The Carvey is an enclosed desktop CNC milling machine
developed by Inventables.

It is designed for smaller fabrication projects,
including signs, engravings, circuit boards,
and small mechanical parts.

This page provides general information about the machine
and links to operating instructions, maintenance records,
and technical documentation.

## Capabilities

- 2D cutting and profiling
- 2.5D milling
- Engraving
- Pocketing and drilling
- Small-scale prototyping
