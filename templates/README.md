# Documentation templates

Templates for contributing documentation to
Fab Lab Ísafjörður.

## Available templates

| Template | Purpose |
|----------|---------|
| general.md | Guides, techniques and general knowledge |
| machine.md | Machine operation and reference |
| project.md | Projects and experiments |
| repair.md | Repairs and maintenance records |

## Using a template

1. Choose the appropriate template.
2. Copy it to the relevant documentation directory.
3. Rename the file or directory appropriately.
4. Replace the example content with your documentation.
5. Remove sections that are not relevant.
6. Add photographs, files, and references where useful.

## Guidelines

- Write in English.
- Use clear, descriptive headings.
- Include photographs and technical details when useful.
- Document failures as well as successes.
- Distinguish verified information from assumptions.
- Link to original sources and project repositories.
- Keep documentation accessible and reproducible.

Documentation does not have to be complete to be useful.
It can be improved over time.
